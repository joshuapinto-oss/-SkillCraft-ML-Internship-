# Task 01 — House Price Prediction

## Objective
Predict house prices using Linear Regression
based on square footage, bedrooms, and bathrooms.

## Dataset
House Price Dataset from SkillCraft Technology

## Libraries Used
- NumPy, Pandas
- Scikit-learn
- Matplotlib, Seaborn

## Model Results
| Metric | Value |
|--------|-------|
| R²     | 0.6598 |
| MAE    | $33,963 |
| RMSE   | $51,079 |

## Features Used
- GrLivArea (Square Footage)
- BedroomAbvGr (Bedrooms)
- FullBath, HalfBath
- BsmtFullBath, BsmtHalfBath
