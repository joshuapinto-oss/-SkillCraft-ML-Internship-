# Task 02 — Customer Segmentation

## Objective
Segment mall customers using K-Means Clustering
based on annual income and spending score.

## Dataset
Mall Customers Dataset from SkillCraft Technology


## Cluster Results
| Cluster | Annual Income (k$) | Spending Score | Profile |
|---------|-------------------|----------------|---------|
| 0       | 55.3              | 49.5           | Mid income, mid spend |
| 1       | 86.5              | 82.1           | High income, high spend |
| 2       | 25.7              | 79.4           | Low income, high spend |
| 3       | 88.2              | 17.1           | High income, low spend |
| 4       | 26.3              | 20.9           | Low income, low spend |

## Features Used
- Annual Income (k$)
- Spending Score (1-100)
